## Sound

Most sound effects come from two packs by **Kenney** (www.kenney.nl), released under
[Creative Commons Zero (CC0)](http://creativecommons.org/publicdomain/zero/1.0/). Crediting them is optional, and we
credit them gladly.

| In the game (`Assets/_Project/Resources/Audio/`) | Pack | Original file |
| --- | --- | --- |
| `Click.ogg`: every button | Interface Sounds 1.0 | `click_002.ogg` |
| `Open.ogg` | Interface Sounds 1.0 | `open_001.ogg` |
| `Place.ogg`: placing a building | Sci-Fi Sounds 1.0 | `impactMetal_002.ogg` |
| `BuildComplete.ogg`: a building finishes | Interface Sounds 1.0 | `confirmation_002.ogg` |
| `Correct.ogg`: right puzzle answer | Interface Sounds 1.0 | `confirmation_001.ogg` |
| `Wrong.ogg`: wrong puzzle answer | Interface Sounds 1.0 | `error_004.ogg` |
| `Beep.ogg`: readings arrived | Interface Sounds 1.0 | `question_002.ogg` |
| `Discovery.ogg`: a value or experiment is known | Interface Sounds 1.0 | `bong_001.ogg` |

These sounds are made in code by `Presentation/Audio/SoundSynth.cs`:
- the space ambience
- the brownout alarm
- the milestone chord
- any fallback for a missing file
